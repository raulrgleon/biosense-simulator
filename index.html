Presets

Glucose sensor

GLUCOSE CALIBRATION — PROVISIONAL. Not a characterized electrode.

I_sensor = glucose · sensitivity + baseline + drift + noise

Baseline and drift are subtracted in the estimate using these configured values. Noise is not removed. Noise changes only while the simulation runs.

Glucose TIA

VCC 3.3 V

fc — · RC —

VOUT = VREF + I(A) · RF

fc = 1 / (2π · RF · CF)

nA is converted to A before the gain. The discrete low-pass runs on VOUT during the simulation. Raise CF to see the lag. This TIA does not share state with the oxygen TIA.

Oxygen sensor

OXYGEN MODEL — PROVISIONAL. Unit “sim” is a simulation scale, not mmHg and not saturation.

VCC 3.3 V

fc — · RC —

I_oxygen = level · sensitivity + baseline + drift + noise

O2 COMPENSATION MODEL: PROVISIONAL. Off, or a coefficient of 0, leaves the glucose channel unchanged. This is not a glucose-oxidase model.

ADC

One converter, three channels. CH1 glucose, CH2 oxygen, CH3 temperature placeholder. Bits and ADC reference are shared. Counts are independent.

count = round(VOUT / VREF_ADC · (2^N − 1))

V_ADC = count / (2^N − 1) · VREF_ADC

Environment

factor = 1 + (k/100) · (T − 37)

TEMPERATURE COMPENSATION — PROVISIONAL. k = 0 disables the effect. This is not a medical temperature compensation. The physical glucose current is multiplied by the factor; the algorithm divides it back out.
